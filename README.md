## 🎯 لماذا تم اختيار هذا التصميم؟

1. **Mobile-First للهواتف الذكية**: 90%+ من زوار إعلانات Google Call Ads يبحثون من هواتفهم. لذلك صُممت الصفحة لتكون واضحة، سريعة القراءة، والخط كبير ومريح للعين على أي شاشة هاتف.
2. **شريط اتصال سفلي ثابت (Sticky Bottom Call Bar)**: عند التصفح من الجوال، يظل زر "اتصل الآن: 66967536" ظاهراً في أسفل الشاشة طوال الوقت لتمكين الزائر من الاتصال بلمسة واحدة دون الحاجة للصعود لأعلى الصفحة.
3. **ألوان الهوية الإنشائية**:
   * **الأسود الفحمي (`#12161b` و `#1c222b`)**: يمنح طابع الصلابة، المقاولات، والاحترافية.
   * **الأصفر الإنشائي التحذيري (`#f59e0b`)**: أعلى درجات التباين والوضوح لتوجيه عين الزائر مباشرة إلى أزرار الاتصال (Call To Action).
   * **الأبيض الناصع (`#ffffff`)**: لنصوص واضحة ومقروءة دون إجهاد للعين.
4. **واقعية وبساطة عملية (No Luxury / No Fake Fluff)**:
   * تم استبعاد الصور الوهمية لرجال الأعمال والمكاتب الزجاجية.
   * جميع الصور تعرض مواقع عمل حقيقية، عمال بناء، خرسانات، وأدوات فعلية تناسب بيئة العمل في الكويت.
   * المحتوى بلهجة عربية واضحة ومباشرة تخاطب العميل الكويتي دون مبالغات أو وعود كاذبة مع توفير خيار الدفع بالأقساط.

## 🔍 الـ SEO و Local SEO المطبق

1. **Semantic HTML5**:
   * وسم واحد فقط رئيسي `<h1>` يستهدف: `مقاولات عامة تكسير وهدم وترميم وأصباغ وديكورات في الكويت - أبو جورج للمقاولات العامة`.
   * وسوم `<h2>` و `<h3>` منظمة هيكلياً للأقسام والخدمات.
2. **Meta Tags مستهدفة**:
   * Meta Title و Meta Description يركزان على الكلمات البحثية الرئيسية في الكويت بدون حشو (Keyword Stuffing).
   * Open Graph و Twitter Cards للمشاركة عبر شبكات التواصل الاجتماعي.
3. **بيانات منظمة Schema.org (LocalBusiness / GeneralContractor)**:
   * مدمجة بصيغة JSON-LD تتضمن اسم النشاط، الهاتف (`+96566967536`)، الدولة الكويت، المحافظات الست المغطاة، وقائمة الخدمات كاملة.
   * خالية من أي تقييمات مزيفة أو معلومات وهمية.
4. **أداء وسرعة عالية (Core Web Vitals)**:
   * جميع الصور مضغوطة ومجهزة بأبعاد صريحة (`width` و `height`) لمنع انزياح التخطيط (CLS = 0).
   * تفعيل التحميل الكسول `loading="lazy"` للصور أسفل الصفحة.
   * انعدام المكتبات الخارجية الثقيلة؛ تحميل الصفحة في أجزاء من الثانية.

## ✏️ كيف تقوم بالتعديل على الصفحة لاحقاً؟

### 1. تغيير رقم الهاتف
افتح ملف `index.html` وابحث عن الرقم `66967536`:
* في رابط الاتصال: استبدل `tel:66967536` برقمك الجديد.
* في كود Schema.org: استبدل `+96566967536`.
* في النصوص الظاهرة: استبدل `66967536`.

### 2. استبدال الصور
جميع الصور موجودة في المجلد `assets/images/`:
* يمكنك ببساطة وضع صورتك الجديدة بنفس الاسم (مثلاً `demolition.jpg` أو `ceramic-tiles.jpg`) لتحل محل الصورة الحالية مباشرة دون الحاجة لتعديل الكود.
* يُفضل أن تكون الصور بنسبة 16:10 أو 4:3 ومضغوطة عبر مواقع مثل [TinyPNG](https://tinypng.com) لتبقى الصفحة سريعة جداً.

### 3. تعديل النصوص والخدمات
* افتح ملف `index.html` في أي محرر نصوص (مثل Notepad أو VS Code).
* النصوص مكتوبة باللغة العربية الواضحة ومقسمة داخل وسوم مثل `<h3 class="service-title">` و `<p class="service-desc">`.

## 🚀 كيفية تشغيل المشروع محلياً

المشروع **Static بالكامل بدون Backend**، لذا يمكنك تشغيله بعدة طرق:

1. **الطريقة المباشرة**: اضغط نقرتين مزدوجتين على ملف `index.html` وسيفتح مباشرة في متصفحك.
2. **عبر خادم محلي تجريبي (Node.js)**:
   ```bash
   npx serve .
   ```
   أو
   ```bash
   npx http-server .
   ```

## 🌐 كيفية نشر المشروع على الإنترنت (Hosting)

نظراً لأن المشروع لا يحتاج إلى أي قواعد بيانات أو خوادم خلفية (100% Static HTML/CSS/JS)، يمكنك نشره مجاناً أو على أي استضافة مدفوعة خلال دقيقتين:

### الخيار 1: استضافة cPanel / أي استضافة في الكويت
1. قم بضغط محتويات المجلد في ملف `.zip`.
2. ادخل إلى لوحة التحكم cPanel -> File Manager -> مجلد `public_html`.
3. ارفع الملف المضغوط وفك الضغط عنه مباشرة.
4. مبروك! الموقع سيعمل فوراً على نطاقك الخاص.

### الخيار 2: Netlify أو Cloudflare Pages أو Vercel (مجاناً وفائق السرعة عالمياً)
1. افتح [Netlify.com](https://www.netlify.com).
2. اسحب مجلد المشروع كاملاً وأفلته في خانة "Drop your folder here".
3. سيتم نشر الموقع فوراً مع شهادة SSL مجانية وسرعة فائقة على شبكة CDN عالمية.

### الخيار 3: GitHub Pages
1. ارفع الملفات إلى مستودع GitHub.
2. من إعدادات المستودع (Settings) -> Pages -> اختر فرع `main` ثم Save.

2. **ماذا يمكن للعميل فعله عبر اللوحة؟**

   * تعديل نصوص وعناوين الخدمات الـ 7.
   * إدخال كود تحويل Google Ads الخاص بحملاته الإعلانية.
   * معاينة شكل الموقع فورياً على شاشة هاتف تفاعلية داخل اللوحة.
3. **تصدير التحديثات**:
   * عند الانتهاء من التعديل، يضغط العميل على زر **"تصدير وتنزيل index.html المحدث"**.
   * يستبدل ملف `index.html` داخل مجلد المشروع بالملف الجديد.
   * يعيد رفع المجلد إلى الاستضافة لتحديث الموقع في ثوانٍ دون كتابة أي كود برمجي.
